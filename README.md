# 泉此方表情包 · 幸运星（AstrBot Meme Pack v2 语义增强版）

《幸运星》泉此方（Izumi Konata）表情包，共 **208 张 PNG**（其中大部分为透明背景贴纸），按聊天回复场景分类，并为每张图附带语义描述、标签和图片内文字，适配支持新版语义包的 AstrBot 表情包管理器。

发布内容不包含任何本机向量、模型配置或密钥；安装后可按使用者自己的向量模型建立本地索引。

## 包信息

- 包 ID：`konata-meme-pack-001`
- 版本：`1.0.0`
- 格式：AstrBot Meme Pack v2 分享版
- 图片文件：208 个（PNG，≤512px）
- 语义记录：208 条（每张图片一条，含内容哈希）
- 本机向量：不包含

## 目录结构

```text
manifest.json
meme_pack_export.json
memes_data.json
semantic_metadata.json
memes/

  cover.jpg
```

## 安装

支持新版语义包的 AstrBot 表情包管理器可以从 GitHub 来源安装：

```text
repo: GitHub-Inull/konata-meme-pack
ref: v1.0.0
subpath: .
```

安装后：

- 已配置向量模型：可按当前模型维度重建本机向量；
- 未配置向量模型：图片、分类和语义描述仍会保留，可继续使用传统分类匹配；
- 旧版插件：可忽略语义文件，继续读取 `manifest.json`、`memes_data.json` 和 `memes/`。

## 素材来源与整理方式

图片来自公开网络（Telegram 幸运星贴纸包的公开镜像、Bing 图片搜索结果），整理流程：

1. 抓取后统一转 PNG、去重（感知哈希）、压缩到 ≤512px；
2. 用视觉模型逐张筛选，只保留出现泉此方的图片（剔除其他角色、真人、纯文字图）；
3. 用视觉模型为每张图生成分类、聊天场景描述、标签与图片内文字；
4. 按 AstrBot Meme Pack v2 分享格式整理，不含本机向量。
